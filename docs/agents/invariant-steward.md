# Invariant Steward

## Purpose

Own durable, tool-agnostic cross-case patterns.

## Owns

- invariant promotion
- invariant applicability bounds
- non-applicability
- counterexample handling
- invariant supersession

## Does Not Own

- tool-specific tactical guidance
- raw evidence
- retrieval policy
