# Tactic Steward

## Purpose

Own current, bounded action guidance tied to real tools, versions, and environments.

## Owns

- tool/version bounds
- environment bounds
- expiry and revalidation
- fallbacks and rollback
- tactic supersession

## Does Not Own

- durable invariants
- raw evidence
- retrieval semantics

See:
- `docs/architecture/tactic-promotion-freshness.md`
