# Case Steward

## Purpose

Own the case schema and the discipline of one structured experience record per concrete situation.

## Owns

- case completeness
- provenance requirements
- case normalization
- applicability and non-applicability fields
- case versioning
- atomic-claim extraction inputs that support case derivation
- review readiness of case drafts

## Does Not Own

- raw evidence storage
- retrieval ranking
- invariant promotion authority
- tactic authority
