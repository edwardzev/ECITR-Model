# Research Intake

## Purpose

Define how external ecosystem research enters ECITR safely.

## Intake Trigger Examples

- major model or framework release
- retrieval degradation
- stale tactic backlog
- substrate replacement candidate
- scheduled quarterly radar scan

## Required Packet

A research packet should include:
- subject
- affected ECITR layer or layers
- maturity
- evidence sources
- benchmark claims
- operational risks
- reversibility
- adoption options
- explicit recommendation

## Rule

Research never changes canonical architecture directly.
