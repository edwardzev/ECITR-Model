# Evaluation

This directory will contain:
- retrieval benchmarks
- layer-specific regression cases
- stale tactic tests
- cross-project leakage tests
- migration validation reports
- external-adaptation evaluation packs
- supporting research notes for design decisions
- planner and runtime baselines
- workflow baselines
- semantic backend research notes
- semantic backend comparison scenarios

Retrieval changes must be benchmarked before acceptance.
External-adaptation proposals must include an evaluation plan before adoption.
