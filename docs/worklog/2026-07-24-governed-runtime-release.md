# Governed Runtime Release

## Scope

This release turns the post-parameter-memory prototype into an operational,
governed ECITR runtime while preserving the canonical authority chain:

`Evidence -> Cases -> Invariants/Tactics`

Parameter records, semantic indexes, and the support graph remain derived or
supporting structures. They do not become canonical truth.

## Included Work

- workspace identity, selective migration, and correction-aware evidence views
- case seeds, bounded case batching, and reviewed live promotion candidates
- model-backed promotion judgment with deterministic activation gates
- tactic revalidation packets and audited lifecycle transitions
- embedded LanceDB retrieval alongside the optional Qdrant prototype
- retrieval abstention, bounded diagnostics, source-lineage diversity, and
  post-fusion support-graph explanations
- project-memory affordances plus opportunity, consultation, and usage metrics
- autonomous refresh with independent derived-index sync
- bounded support-graph snapshots, diffs, scheduler reports, and log rotation

## Validation

- all schema fixtures validate
- `npm run check` passes with 273 tests
- retrieval regression assets cover abstention, forbidden results, scope,
  correction visibility, and explanation-only graph enrichment
- generated `.local` catalogs, indexes, graphs, reports, and invocation logs
  remain excluded from version control
